# macOS platform port

This folder contains the C++, Objective-C and Objective-C++ code for the macOS
platform port.

This platform uses shared Apple code ([`backends/apple`](/backends/apple)).

See also [`dist/macos`](/dist/macos) folder for additional files used
by this platform. [`dist/macos_tools.app`](/dist/macos_tools.app) is
an `.app` bundle template used for packaging the macOS editor, while
[`dist/macos_template.app`](/dist/macos_template.app) is used for
packaging macOS export templates.
