# orblit_path

Curves to follow and ways across ground: splines with tilt, rails and
patrols, and grid and navmesh pathfinding that walks an agent round a wall.

Part of [Orblit](https://github.com/ChxisB/orblit), a Dart-first 3D game
engine. The documentation is at [orblitengine.com](https://orblitengine.com).

## Using it

```yaml
dependencies:
  orblit_path:
    git:
      url: https://github.com/ChxisB/orblit.git
      path: packages/orblit_path
```

Needs Dart alone. Runs anywhere Dart runs, including a headless CI runner.
